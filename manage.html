เข้าสู่ระบบผู้ดูแล

กรอก username และ password ของบัญชีผู้ดูแล

ตั้งค่าผู้ดูแลครั้งแรก
  1. ใน Apps Script → Project Settings → Script Properties เพิ่ม ADMIN_BOOTSTRAP_PASSWORD เป็นรหัสเริ่มต้นที่คุณตั้งเอง ความยาว 8-128 ตัวอักษร
  2. ในหน้า Apps Script เลือกฟังก์ชัน setupInitialAdmin แล้วกด Run เพื่อสร้างชีต user และบัญชี robojorj
  3. หากมีบัญชี robojorj อยู่แล้ว ให้เลือก resetInitialAdminPassword เพื่อเปลี่ยนเป็นรหัสใหม่
  4. ฟังก์ชันจะลบค่า bootstrap password หลังสร้างหรือรีเซ็ตรหัสผ่าน โดยเก็บรหัสผ่านเป็น hash ไม่เก็บเป็นข้อความ
  5. Deploy Apps Script เวอร์ชันใหม่ก่อนเริ่มใช้งาน
